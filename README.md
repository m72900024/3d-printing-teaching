# 3D 列印入門教室

給初次接觸 FDM 3D 列印的教師、學生與研習學員使用的互動教學網站。

## 第一版內容

- 七章 FDM 學習路徑
- Bambu Studio 與 Bambu Lab A1／P1S 基礎介紹
- 常見列印問題分類
- 可儲存的章節進度與列印前檢核表
- 手機、平板與桌面響應式版面

## 本機預覽

使用任何靜態網站伺服器開啟專案根目錄即可，例如：

```bash
python -m http.server 4173
```

然後開啟 `http://localhost:4173`。

## 發布

推送至 `main` 後，GitHub Actions 會自動部署至 GitHub Pages。
