# 課程 04：模型平台與 3MF 時代

## 重製目的

原課程只簡短比較 STL、3MF 與授權。新版改以學生實際下載模型會遇到的問題為核心：平台提供什麼、檔案位於工作流程哪一層、3MF 是否帶有切片設定、以及內容能否安全套用到教室設備。

## 課程架構

1. 從單色 STL 到 3MF 專案。
2. Thingiverse、Printables、MakerWorld 三平台特色。
3. 原始 CAD、模型交換檔、切片專案、機器指令四個層級。
4. 為什麼 3MF 仍不能不檢查就直接列印。
5. 來源、授權、尺寸、零件、材料、機型六項檢查。
6. Creative Commons 與校園安全。

## 研究依據

- Thingiverse 更新紀錄顯示平台支援 STL、3MF、OBJ，並提供開啟至多種切片軟體的流程。
- Printables 模型頁可同時呈現 Model Files 與特定設備的 Print Files，課程因此加入 G-code 相容性提醒。
- MakerWorld FAQ 說明 Print Profile 是 Bambu Studio 的 3MF，可包含模型、擺放、方向、速度、強度、支撐、平台黏附與顏色資訊。
- 3MF Consortium 說明 3MF 可保存 STL 缺少的單位、顏色、材料與拓樸等資訊，但實際軟體專案內容仍取決於產生檔案的應用程式。
