# A01 線材乾燥與保存｜圖片提示詞

共通規格：`scientific-educational` 網頁課程圖解，1536×1024 橫式，活潑日系動漫教學風，乾淨奶油白背景，青綠、珊瑚橘、明黃與紫色點綴，清楚粗線條。設備為無品牌的桌上型 FDM 3D 印表機與線材捲盤；不出現商標、浮水印、簡體字、英文長句、危險操作或把線材放入家用烤箱的畫面。

## 1. dry-vs-damp.webp

左右對照同一個學生與同一台 FDM 印表機：左邊乾燥線材平順出料、作品表面乾淨；右邊受潮線材在噴嘴冒出細小蒸氣泡、成品拉絲且表面粗糙。正上方只放兩個繁體中文大標籤：「乾燥」「受潮」。以箭頭指出乾燥線材與受潮線材的差異，構圖簡單、科學正確。

## 2. moisture-risk.webp

以放大剖面呈現線材吸收空氣水氣：左側是潮濕空氣中的水滴進入線材捲盤，中間是加熱噴嘴內水氣變成小氣泡，右側分成拉絲、孔洞、粗糙表面、強度下降四個小視窗。只放繁體中文標籤：「吸濕」「氣泡」「品質下降」。不可畫成爆炸或火災。

## 3. drying-decision.webp

動漫學生拿著檢查板，依序判斷線材：密封紀錄、是否有拉絲／爆裂聲／孔洞、先用小型測試件確認、再決定乾燥。用從左到右的四步驟流程與大箭頭，只放繁體中文短標籤：「查紀錄」「看症狀」「小件測試」「再乾燥」。強調先觀察再處理。

## 4. drying-methods.webp

安全方法比較圖：左側為有溫控與計時顯示的專用線材乾燥箱，標示綠色勾；右側為開放式懸臂 FDM 印表機的熱床，上方有醒目禁止符號，學生把線材移開。只放繁體中文短標籤：「專用乾燥箱」「A1／A1 mini 禁止熱床乾燥」。不可出現家用烤箱，不顯示具體溫度。

## 5. storage-workflow.webp

從左到右五步循環：線材冷卻、放入密封袋或密封箱、加入乾燥劑、放入濕度卡、貼日期與材料標籤；旁邊有整齊收納架。只放繁體中文標籤：「冷卻」「密封」「乾燥劑」「濕度卡」「做紀錄」。畫面鼓勵乾燥後立即密封保存。
