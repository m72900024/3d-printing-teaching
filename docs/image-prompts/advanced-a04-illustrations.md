# A04「依作品需求選擇線材」圖像提示詞

## 共通視覺規格

- Use case：scientific-educational
- Asset type：進階 3D 列印課程段落圖解
- 尺寸與構圖：3:2 橫式，1536×1024；所有文字與重要作品距離邊緣至少 8%，不可被裁切。
- 風格：活潑但專業的日系動漫教室插畫，乾淨淺色背景、深紫與青綠主色、少量萊姆綠重點色；同一位短深棕髮、綠色工作圍裙的成年女性教師。
- 教學原則：主畫面優先呈現實際作品與可視化特性實驗；短標籤最多 4–6 個，不做滿版規格表、警告海報或密集小字。
- 文字：只允許提示詞中引號內的繁體中文，字體清晰端正；禁止簡體中文、日文、英文段落、品牌商標、水印、價格、溫度與虛構性能分數。

## 01｜作品需求六問

Use case: scientific-educational
Asset type: A04 課程 3:2 橫式功能圖解
Primary request: 教師站在中央工作桌前，周圍以六個清楚場景展示選材前的作品需求：室內展示模型、戶外感測器遮罩、靠近熱源的功能外殼、承受重量的支架、可彎曲保護套、表面細緻的角色模型。
Style/medium: polished Japanese anime educational illustration, clean vector-like finish
Composition/framing: 六個場景環繞中央教師，每個場景有大圖示與一個短標籤，留白充足
Text (verbatim): "室內或戶外", "環境溫度", "受力方式", "需要彎曲", "外觀需求", "後加工"
Constraints: 六個標籤各出現一次；所有作品完整可見；no logos, no watermark
Avoid: 材料排名、數字表格、噴嘴或 AMS 警告

## 02｜線材功能地圖

Use case: scientific-educational
Asset type: A04 課程 3:2 橫式功能圖解
Primary request: 同一個桌上支架被放進不同使用情境，形成由需求走向材料候選的視覺地圖；PLA 對應精緻模型，PETG 對應日常耐用，ASA 對應戶外，TPU 對應可彎曲，PC/PA 對應工程功能，CF/GF 對應高剛性治具。教師用手指向中央作品，強調沒有單一材料適合所有情境。
Style/medium: lively anime classroom infographic, large product illustrations, minimal labels
Composition/framing: 中央作品，六條彩色路徑通往六個功能場景，不能像資料表
Text (verbatim): "容易列印", "日常耐用", "戶外耐候", "柔性回彈", "工程功能", "剛性穩定"
Constraints: 標籤清晰且各出現一次；材料捲軸只用通用色彩與材料縮寫，不放商標；no watermark
Avoid: 星等、冠軍、最強、固定溫度、密集數字

## 03｜PLA 與 PETG

Use case: scientific-educational
Asset type: A04 課程 3:2 橫式功能比較圖
Primary request: 左側 PLA 展示精緻角色模型、尺寸原型與桌面收納盒，線條俐落；右側 PETG 展示工具掛架、卡扣盒與輕微彎曲後回復的耐用零件。教師在中間拿著相同形狀試片，引導比較外觀、韌性與使用情境。
Style/medium: professional anime educational illustration with realistic 3D printed layer texture
Composition/framing: 左右並排，各三個大型實際作品；底部只放四個特性短標籤
Text (verbatim): "PLA｜細節與原型", "PETG｜韌性與耐用", "尺寸穩定", "可輕微彎曲"
Constraints: 所有文字完整清晰；作品不裁切；no logos, no watermark
Avoid: 食品安全暗示、魚缸用途、絕對耐熱宣稱、固定溫度

## 04｜ABS 與 ASA

Use case: scientific-educational
Asset type: A04 課程 3:2 橫式功能比較圖
Primary request: 左側 ABS 是靠近溫熱設備的非安全關鍵功能外殼與室內支架；右側 ASA 是戶外感測器遮罩、陽台固定座與標示牌，背景有陽光與雨滴。教師在中央比較翹曲試片與完整作品，表現兩者需要更受控的列印環境。
Style/medium: clean anime technical illustration, tangible printed parts
Composition/framing: 左右兩個清楚場景，主體是作品用途，不畫參數表
Text (verbatim): "ABS｜耐熱功能件", "ASA｜戶外耐候", "受控環境", "留意翹曲"
Constraints: 不描繪臨時罩體；所有標籤清晰；no logos, no watermark
Avoid: 有毒或無毒的絕對宣稱、固定溫度、戶外永久不老化暗示

## 05｜TPU 柔性與回彈

Use case: scientific-educational
Asset type: A04 課程 3:2 橫式功能圖解
Primary request: 教師用手壓縮 TPU 防滑腳墊，旁邊依序展示手機保護套、密封圈、線材護套與緩衝墊；以三格連續動作顯示壓縮、彎曲、回彈。另用相同外形但不同壁厚的兩件試片表現幾何也會改變軟硬感。
Style/medium: lively anime educational illustration, tactile soft material rendering
Composition/framing: 大型柔性作品占畫面，多個清楚動作箭頭，短標籤不超過五個
Text (verbatim): "柔性", "壓縮", "彎曲", "回彈", "壁厚也會影響手感"
Constraints: 動作順序清楚；所有作品完整；no logos, no watermark
Avoid: AMS 圖示、硬度數值、醫療或人體植入用途

## 06｜PC 與 PA 尼龍

Use case: scientific-educational
Asset type: A04 課程 3:2 橫式工程材料圖解
Primary request: 左側 PC 防護外殼接受落球衝擊後仍維持形狀，旁邊是耐熱功能外殼；右側 PA 尼龍展示齒輪、鉸鏈與反覆活動卡扣。教師拿著乾燥線材袋，遠處以小水氣圖示提醒 PA 吸濕，但主畫面仍以工程作品為主。
Style/medium: polished anime engineering classroom illustration, clear mechanical parts
Composition/framing: 左右功能場景加中央教師，落球、齒輪轉動與鉸鏈開合用簡潔動態線表示
Text (verbatim): "PC｜耐衝擊與耐熱", "PA｜韌性與活動零件", "反覆受力", "留意吸濕"
Constraints: 只做相對特性說明；不放承重數字；no logos, no watermark
Avoid: 安全帽、生命安全設備、固定溫度、絕對不破裂

## 07｜CF／GF 功能件

Use case: scientific-educational
Asset type: A04 課程 3:2 橫式複合材料功能圖
Primary request: 大型主畫面展示 CF/GF 複合線材製作的定位治具、L 型支架、小型機器手臂連接件與尺寸穩定功能外殼。下方以相同長條試片受同樣力量的並排實驗，基礎材料彎曲較明顯、加入短纖填料的複合材料較挺。教師指向剖面中的短纖填料，僅以一個短註解說明不是連續纖維結構。
Style/medium: professional anime technical illustration, visible matte composite texture
Composition/framing: 作品占三分之二畫面，受力比較占下方三分之一，無設備警告角標
Text (verbatim): "治具", "支架", "機器手臂零件", "剛性與尺寸穩定", "短纖填料"
Constraints: 五個標籤各出現一次；不畫噴嘴、AMS 或警告表；no logos, no watermark
Avoid: 連續纖維布紋、金屬般不可彎曲、強度數字、最強材料宣稱
