# A02 品質問題診斷｜圖片提示詞

共通規格：`scientific-educational` 網頁課程圖解，1536×1024 橫式，活潑日系動漫教學風，乾淨奶油白背景，青綠、珊瑚橘、明黃與紫色點綴，清楚粗線條。設備為無品牌桌上型 FDM 3D 印表機；不出現商標、浮水印、簡體字、英文長句、火災、徒手碰熱噴嘴或拆電氣零件。

## 1. diagnostic-loop.webp

中央是一位學生拿著單一變因紀錄表，周圍是順時針五步驟診斷循環：症狀、可能原因、安全檢查、只改一項、小件重測。只放繁體中文大標籤：「看症狀」「列原因」「先檢查」「只改一項」「小件重測」。箭頭清晰連成循環。

## 2. extrusion-symptoms.webp

三欄動漫科學圖解：拉絲像細蜘蛛絲、出料不足造成缺線、堵塞造成噴嘴無料；下方以線材受潮、送料阻力、溫度／速度不合的簡單圖示連到症狀。只放繁體中文標籤：「拉絲」「出料不足」「堵塞」「先分辨」。不可畫火焰。

## 3. warping-layer-cracks.webp

左右對照：左邊大型平板模型四角翹起，顯示平台附著與收縮方向；右邊高塔模型層間裂開，顯示冷卻、環境風與層間結合。只放繁體中文標籤：「翹曲」「層裂」「附著」「收縮」。人物只觀察與按暫停，不徒手碰觸。

## 4. bridge-seam-surface.webp

三個放大視窗比較：橋接下垂、接縫凸點、表面粗糙；學生使用切片預覽與單一變因試片來比對。只放繁體中文標籤：「橋接」「接縫」「表面」「單一變因」。線條清楚，可一眼辨認三種症狀。

## 5. a1-p1s-heat-creep.webp

左右兩台無品牌 FDM 印表機案例：左為開放式懸臂機型概念（A1），右為封閉式 CoreXY 機型概念（P1S）。中央用噴頭剖面放大顯示冷端線材因熱往上累積而提早軟化、變粗、送料受阻；冷端風扇以藍色氣流顯示散熱。封閉機旁顯示腔體熱氣，開放機旁顯示環境溫度與風扇檢查。只放繁體中文標籤：「A1」「P1S」「熱蠕變／熱堆積」「冷端散熱」「送料受阻」。不畫成噴嘴外部著火或機器熔化。
