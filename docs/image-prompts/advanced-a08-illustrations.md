# A08 教學圖解生成提示詞

共同設定：Use case 為 scientific-educational。3:2 橫式網站教學圖，活潑但精準的動漫教室插畫，象牙白背景、深紫與薄荷綠主色、珊瑚色警示，粗線條與大區塊排版。只使用繁體中文，標題和標籤必須清楚、短而正確；功能性資訊優先於裝飾。不要品牌商標、不要浮水印、不要假裝成真實 Bambu Studio 截圖、不要日文或簡體中文。所有示意數值只作候選編號，不提供通用 K 值或流量倍率。

## calibration-decision.webp

畫一條由左至右的四步決策流程。步驟一「線材乾燥？」搭配乾燥線材和水滴警示；步驟二「送料順暢？」搭配線盤、進料管和堵塞叉號；步驟三「預設正確？」搭配材料卡與噴嘴直徑；步驟四「症狀可重複？」搭配兩個相同測試件。結尾分支為綠色「開始校正」與灰色「先排除原因」。Exact text:「校正前先檢查」「線材乾燥？」「送料順暢？」「預設正確？」「症狀可重複？」「開始校正」「先排除原因」。

## dynamics-vs-flow.webp

左右對照圖。左欄標題「Flow Dynamics」，畫噴嘴經過加速、轉角、減速，熔料線在轉角維持一致，箭頭標示「速度改變」「壓力響應」「看轉角」。右欄標題「Flow Rate」，畫噴嘴在穩定速度下鋪出一整片相鄰線條，標示「穩定出料」「整體料量」「看表面」。中央以叉號表示兩者不能互相取代。Exact text:「Flow Dynamics」「速度改變」「壓力響應」「看轉角」「Flow Rate」「穩定出料」「整體料量」「看表面」「不能互相取代」。

## dynamics-corners.webp

三欄比較同一條直角列印路徑，進料方向箭頭一致。左欄「補償不足」：轉角前後線條變細、轉折不完整；中欄「較穩定」：線寬連續、轉角乾淨；右欄「補償過度」：轉角出現凹陷或不自然收縮。下方加一條判讀提示「看完整轉角，不看單一小點」。Exact text:「補償不足」「較穩定」「補償過度」「線條變細」「線寬連續」「凹陷」「看完整轉角，不看單一小點」。

## flow-rate-surfaces.webp

上半部「第一輪：粗選」，排列五個有候選編號的方形測試片；下半部「第二輪：細選」，排列三個更接近的測試片。用放大鏡顯示線間細縫、平整相接、互相推擠三種表面。旁邊加入低角度眼睛圖示與冷卻後手指輕觸圖示。Exact text:「Flow Rate 判讀」「第一輪：粗選」「第二輪：細選」「線間細縫」「平整相接」「互相推擠」「完全冷卻再觸摸」。

## extrusion-cross-section.webp

三欄剖面圖，畫相鄰擠出線條落在同一層。左欄「擠出不足」線條之間有明顯空隙；中欄「適中」線條互相接合且高度一致；右欄「過度擠出」線條互相推擠並向上隆起。用垂直箭頭標示表面高低，清楚連結剖面與上方看到的表面。Exact text:「擠出不足」「適中」「過度擠出」「空隙」「相接」「隆起」。

## profile-naming.webp

畫一張線材預設卡與四個欄位被依序填入：材料「PETG」、品牌系列「範例系列」、噴嘴「0.4 mm」、日期「2026-08」。旁邊放測試片照片縮圖、乾燥狀態、Bambu Studio 版本和校正結果紀錄符號。原始系統預設放在左側並加鎖頭，自訂副本放右側。Exact text:「不要覆蓋原始預設」「建立自訂副本」「材料」「品牌系列」「噴嘴」「日期」「乾燥狀態」「測試照片」。

## before-after-verification.webp

左右完全相同的 L 型小型測試件，具直線、90 度轉角和平坦頂面。左側「校正前」、右側「校正後」，中間只有一個變因箭頭「只換材料預設」。下方四個共同檢查框為「轉角」「頂面」「尺寸」「新缺陷」，並畫相機相同角度與游標卡尺相同位置。不要保證右側必定比較完美，以「比較後決定」作結。Exact text:「校正前」「校正後」「只換材料預設」「轉角」「頂面」「尺寸」「新缺陷」「比較後決定」。
