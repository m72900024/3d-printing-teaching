# 第十二課原創教學圖提示詞

三張圖使用 Codex 內建 `imagegen` 生成，再轉為 1536×1024 WebP。Bambu Lab Wiki 圖片未作為影像輸入。共同要求：3:2 橫式、臺灣繁體中文、現代臺灣教學漫畫、奶油紙張底色、森林綠／萊姆綠／橘／藍配色、16:10 安全裁切、無日文、簡體字、商標與水印。
