# 第九課原創教學圖提示詞

三張圖使用 Codex 內建 `imagegen` 生成，再轉為 1536×1024 WebP。Bambu Lab Wiki 圖片未作為影像輸入。共同要求：3:2 橫式、臺灣繁體中文、現代臺灣教學漫畫、奶油紙張底色、森林綠與萊姆綠主色、橘色警示、藍色資訊、16:10 安全裁切、無日文、簡體字、商標與水印。

## 方向、橋接與支撐

- 輸出：`assets/course-09/illustrations/orientation-bridge-support.webp`
- 來源：[Bambu Lab Wiki｜Auto Orientation](https://wiki.bambulab.com/en/software/bambu-studio/auto-orientation)

```text
同一個帶水平臂的模型做三欄判斷：旋轉到大平面貼床、兩端都有支點的短橋接、只有單側連接且需要暫時支撐的長懸空。標題只使用「改變方向」「短距橋接」「需要支撐」，讓橋接與單側懸空清楚不同。
```

## 一般與樹狀支撐

- 輸出：`assets/course-09/illustrations/normal-vs-tree-support.webp`
- 來源：[Bambu Lab Wiki｜Slow Down for Overhangs](https://wiki.bambulab.com/en/software/bambu-studio/slow-down-for-overhang)

```text
用同一個角色模型比較直柱／網格式一般支撐、分枝接觸曲面的樹狀支撐，以及冷卻拆除後的接觸痕跡和鬆散支撐。標題只使用「一般支撐」「樹狀支撐」「拆除比較」。
```

## 平台附著輔助

- 輸出：`assets/course-09/illustrations/adhesion-aids.webp`
- 來源：[Bambu Lab Wiki｜Brim](https://wiki.bambulab.com/en/software/bambu-studio/auto-brim)

```text
三個紋理鋼板俯視圖：與模型分離、只確認出料的裙邊；連接細腳模型、增加接觸面的帽沿；在困難模型下建立完整底座、耗材最高的底筏。標題只使用「裙邊」「帽沿」「底筏」。
```
