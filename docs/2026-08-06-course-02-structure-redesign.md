# 課程 02：安全與機器構造重整

日期：2026-08-06

## 教學方向

原課程直接比較 A1 與 P1S，知識較容易綁定特定廠牌。本次改為兩層架構：

1. 先辨認所有 FDM 印表機共通的線架、送料路徑、熱端、噴嘴、熱床與平台。
2. 再以「誰負責 X、Y、Z 移動」比較龍門式、三角洲式與 CoreXY。

CoreXY 以常見箱型框架呈現，但內文明確提醒「箱型外觀不等於 CoreXY」，仍應從馬達與皮帶分工判斷。

## 課程順序

1. 通用 FDM 工作系統。
2. 三種機構的外形與運動方法。
3. 噴頭、平台移動方式比較表。
4. 品牌中立的危險來源。
5. 異常時先暫停、等停止、看溫度、再由教師處理。
