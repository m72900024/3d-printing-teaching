# 課程 02：FDM 共通工作系統實物照片

## 修改目的

原本「供料、送料、加熱、承托」只有文字卡，初學者不容易把名稱和真實機器部位連結。本次改為四張實物照片搭配原有說明，並新增「照片觀察」提示，引導學生依材料旅程辨認部件。

## 教學與版面設計

- 延續「從捲盤一路追到平台」的材料旅程，不綁定特定品牌或型號。
- 每張卡保留系統名稱和作用，另加一句照片辨認提示。
- 桌機使用 2×2 圖文卡，700px 以下改成單欄，避免文字與照片被擠壓。
- 圖片統一處理成 900×600 WebP；保留原圖比例重點並降低頁面下載量。
- 圖片使用描述性替代文字，來源連結可直接開啟授權頁。

## 驗證項目

- JavaScript 語法檢查。
- HTML 實際載入四張圖片，確認來源連結、替代文字和卡片數量。
- 桌機與手機尺寸檢查欄數、文字可讀性和水平溢位。
- Git 差異與空白格式檢查。
