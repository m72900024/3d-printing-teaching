# 課程 03：從模型到成品圖文重製

## 教學目標

原版只有建模、切片與列印三段短文字。本次改用同一個桌面收納盒作為貫穿案例，讓學生追蹤它如何從需求、數位幾何、切片路徑一路成為實體作品。

## 內容結構

1. 從需求到 3D 模型：需求、草圖、尺寸、建模或合法取得模型，輸出 STL／3MF。
2. 切片軟體負責翻譯：加入機器、噴嘴、材料與參數，檢查逐層路徑。
3. 傳送、觀察與完成列印：送出前檢查、觀察第一層、冷卻取件與成品回饋。

每個步驟固定呈現「輸入、主要動作、輸出」，幫助學生分辨模型檔、切片專案與機器指令。

## GPT 圖像

- `00-workflow-overview.webp`：建模、彩色切片、FDM 列印的三階段總覽。
- `01-modeling.webp`：從收納需求與草圖建立 3D 模型。
- `02-slicing.webp`：查看外殼、填充、支撐與逐層預覽。
- `03-printing.webp`：保持安全距離觀察第一層與完成品。

四張圖均使用內建圖像生成功能獨立產生；不放品牌標誌或圖中文字。原始 1536×1024 PNG 轉為 1200×800 WebP，品質 86。

## 版面與無障礙

- 課程總覽使用大幅漫畫與三個中文導讀重點。
- 三個步驟各有大圖、圖說與三欄資訊；窄螢幕改成單欄。
- 學習目標在桌機顯示三張插圖卡，手機切換為小圖加文字。
- 所有圖片均有描述內容與教學意義的繁體中文替代文字。
