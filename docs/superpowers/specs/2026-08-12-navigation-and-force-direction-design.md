# 全站分層導覽與 A05 受力方向課程設計

## 目標

本次改版同時解決兩個問題：

1. 學習者在首頁或課程讀到一半時，能清楚知道如何回到網站首頁、課程總覽或其他課程。
2. 新增進階 A05「受力方向與列印方向」，以功能零件與破壞測試教會讀者依受力選擇模型擺放方式。

所有介面與課文使用繁體中文。保留既有課程內容、完成狀態、上一課／下一課與視覺語言，不進行無關重構。

## 一、全站分層導覽

### 首頁桌面導覽

首頁上方保留三個主要入口：

- 初階課程
- 進階課程
- 網站介紹

「初階課程」以可點擊、可鍵盤操作的分層選單展開：

- 第一次成功：01–06
- 理解與調整：07–09
- 獨立完成：10–12

每個階段顯示階段名稱、課程編號與課名。階段是資訊分組，不增加中繼頁；點課名直接開啟課程。

「進階課程」直接列出 A01–A05，因為目前課程數量少，不再增加第二層。

選單支援滑鼠點擊、鍵盤 Enter／Space、Escape 關閉、點擊選單外關閉，並以 `aria-expanded`、`aria-controls` 與正確導覽標籤說明狀態。滑入可輔助展開，但不能成為唯一操作方式。

### 首頁手機導覽

寬度 900px 以下將頂部連結收進「☰ 導覽」按鈕。選單以手風琴呈現：

- 初階課程：展開三個階段，再顯示各堂課
- 進階課程：展開 A01–A05
- 網站介紹：直接跳至介紹段落

一次只展開一個主要層級；選擇課程後關閉選單。開啟時鎖住背景捲動，Escape、遮罩與關閉按鈕皆可離開。

### 課程閱讀頁頂部

所有 12 堂初階與 A01–A05 使用一致的固定頂部導覽：

- 「網站首頁」：初階頁為 `../index.html`，進階頁同樣回到 `../index.html`
- 「初階課程總覽」：回到 `../index.html#path`
- 「進階課程總覽」：回到 `index.html`
- 右側顯示目前階段與課程編號

手機版不得再把不同目的地都縮寫成「← 首頁」。按鈕文字要明確區分「網站首頁」與「課程總覽」。空間不足時可以使用圖示，但仍保留可見短文字及完整 `aria-label`。

### 課程側邊欄

側邊欄最上方加入固定入口：

- 網站首頁
- 本層級課程總覽

初階課程清單依三個階段分組；進階課程清單列出 A01–A05。各組使用可見標題，但不要求折疊，以免使用者還要額外操作才能換課。當前課程保留高亮與 `aria-current="page"`。

### 導覽資料與元件邊界

課程名稱與網址仍以 `course-data.js`、`advanced-course-data.js` 為唯一課程資料來源。新增的小型導覽模組只負責：

1. 依課程資料建立分組清單。
2. 控制桌面下拉與手機手風琴狀態。
3. 設定鍵盤、遮罩、焦點與無障礙屬性。

靜態 HTML 必須保留首頁、課程總覽與基本課程連結，讓 JavaScript 失效時仍能返回主要頁面。`scripts/build-site.js` 需繼續輸出正確的靜態課名、前後導覽與資源指紋。

## 二、A05「受力方向與列印方向」

### 課程定位

- 編號：A05
- 階段：結構設計
- 時長：約 40 分鐘
- 類型：受力判讀＋破壞實驗

本課不重複初階第 07 課的基本擺放與切片預覽，也不重複 A03 的支撐參數。核心問題是：「作品使用時，力量從哪裡進入、經過哪裡、可能沿哪裡破壞？」

### 學習成果

完成本課後，學習者可以：

1. 分辨拉伸、壓縮、彎曲、剪切與扭轉。
2. 解釋 XY 連續列印線與 Z 層間接合造成的方向性。
3. 在掛鉤、支架、螺絲孔與卡扣上標出固定點、外力、傳力路徑與可能破壞面。
4. 比較平放、側放、直立的強度、支撐、外觀與時間取捨。
5. 在 Bambu Studio 預覽中檢查外殼、孔周路徑、填充方向與接縫。
6. 以固定小件進行單一變因破壞測試並留下紀錄。

### 課程段落

1. **先畫力，不先旋轉模型**
   - 介紹五種基本受力。
   - 先標固定點與力的方向，再判斷零件哪一側受拉、哪一側受壓。

2. **線條、層面與異向性**
   - 解釋 FFF 成品沿不同方向可能呈現不同機械表現。
   - 避免把「Z 軸較弱」寫成永遠成立的單一排名；材料、溫度、幾何與列印品質都會改變結果。

3. **同一支架的三種列印方向**
   - 比較平放、側放、直立。
   - 每種擺法同時呈現傳力路徑、可能裂縫、支撐量、接觸面與列印高度。

4. **四種功能零件案例**
   - 掛鉤：彎曲造成的拉伸側與壓縮側。
   - L 型支架：內角應力集中與圓角改善。
   - 螺絲孔／螺絲座：鎖固力與沿層剝離風險。
   - 卡扣：反覆彎曲位置、根部圓角與列印線方向。

5. **方向、外殼與填充的調整順序**
   - 先改善傳力方向與幾何。
   - 再調整外殼圈數與孔周圍連續路徑。
   - 最後把填充密度或方向當作單一變因測試，不把 100% 填充視為通用答案。

6. **回到 Bambu Studio 預覽**
   - 依官方軟體名稱標示外殼、填充、填充方向、接縫與逐層預覽。
   - 要求學習者在送出前查看關鍵截面，不只看模型外觀。

7. **固定條件破壞測試**
   - 同一模型、材料、機型、噴嘴、層高、外殼與填充，只改列印方向。
   - 記錄負載方式、變形、最大承重、破壞位置與裂縫方向。
   - 測試只用安全的小型教具與低風險載重；不得拿人體、懸吊重物或安全關鍵零件當測試對象。

## 三、教學圖的標註系統

圖片數量不硬性限制為七張。先製作七張核心圖；若螺絲孔、卡扣、切片預覽或破壞測試在同一張圖中無法保持大字與清楚箭頭，就拆成獨立細節圖，預計總量為 7–10 張。判斷原則是「一張圖只回答一個主要問題」，不得為了減少張數縮小文字或讓箭頭交疊。

每張圖使用一致的圖例：

- 藍色實線箭頭：外力方向
- 黃色固定點：鎖固或支撐位置
- 綠色線條：連續列印線與較有利的傳力方向
- 紫色橫線：層與層的堆疊方向
- 紅色虛線：可能的裂縫或剝離面
- `XY`／`Z`：列印座標

每張圖左下角固定放小圖例，使用繁體中文，控制在 5–8 個主要標籤。箭頭必須直接指向對象，避免文字漂浮。若需要更多說明，改用第二張局部放大圖或圖片下方的編號解讀，不在主圖堆疊小字。判斷語句使用「此受力情境較有利」「可能沿層面剝離」，不使用沒有條件的「最強」「一定會斷」。

七張核心圖分別為：

1. 五種受力方向圖例。
2. XY 連續線與 Z 層間接合剖面。
3. 同一支架三種列印方向比較。
4. 掛鉤的固定點、載重、拉伸側、壓縮側與裂縫起點。
5. 螺絲孔、螺絲座與卡扣的力與剝離位置。
6. Bambu Studio 外殼、孔周路徑、填充與接縫預覽。
7. 三種方向的小件破壞測試與紀錄方式。

可依內容清晰度增加三類細節圖：

8. **螺絲孔局部剖面**：分開標示徑向撐開力、孔周外殼、螺絲座根部與可能沿層剝離面。
9. **卡扣動作連續圖**：以「壓入 → 最大彎曲 → 回彈定位」三格呈現，標出根部受拉側、圓角與列印線方向。
10. **切片與斷面對照圖**：左側為 Bambu Studio 關鍵層預覽，右側為實際斷裂試片，使用相同編號連結外殼、填充、接縫與裂縫位置。

每張主圖下方搭配 3–5 點編號解讀，順序固定為「先看外力 → 再看固定點 → 沿綠線追蹤傳力 → 最後看紅色可能破壞面」。圖片中的編號與課文解說必須一一對應，讓手機畫面即使縮小仍可由下方文字理解。

圖片延續現有動漫教室風格與同一位教師角色，但工程標註優先於裝飾。所有圖片以 3:2 WebP 輸出並使用 `object-fit: contain`，避免課程圖片再次被裁切。

## 四、來源策略

力學觀念使用原始研究與設備／材料製造商設計指南。Bambu Lab Wiki 若沒有專門的受力方向文章，不強行標成 Bambu Wiki 來源；Bambu Studio 操作則引用 Bambu Lab 官方 Wiki、官方 GitHub 專案或目前版本的實際介面。

預定主要來源：

- UltiMaker《How to design for FFF 3D printing》
- Stratasys《Design Considerations: FDM Additive Manufacturing Tooling》
- Prusa Knowledge Base《Modeling with 3D printing in mind》與《Infill》
- Bambu Lab 官方 BambuStudio 專案與製程設定
- 經同儕審查的列印方向與機械異向性研究

社群模型只作為功能情境案例，並明確標示不等於官方性能認證。

- 首頁桌面可用滑鼠與鍵盤開啟初階三階段及進階 A01–A05。

- A05 靜態頁、進階總覽與首頁顯示第 5 堂進階課程。
- 至少七張核心圖片皆為 3:2、完整顯示、繁體中文且有一致圖例；需要時增加至十張，不以縮小文字取代細節圖。
- 每張圖的編號標示與下方 3–5 點解讀一一對應。
- 課文包含五種受力、XY／Z、四種零件案例、Bambu Studio 預覽與單一變因測試。
- 官方／研究來源連結可直接開啟，社群案例與性能認證有清楚區隔。
