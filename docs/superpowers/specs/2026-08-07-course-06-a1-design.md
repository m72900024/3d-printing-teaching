# 第六課 A1 第一次列印改版設計

## 目標

把第六課「完成第一次列印」從三段式摘要擴充為可跟著操作的 Bambu Lab A1 實作課。學生完成後，能核對列印條件、從 Bambu Studio 傳送工作、判讀第一層、在異常時安全停止，並於平台冷卻後取件。

## 範圍

- 第六課只以 Bambu Lab A1 作為示範機型。
- 使用 PLA、0.4 mm 噴嘴、紋理 PEI 平台與 0.20 mm 標準預設作為第一次列印的共同情境。
- 保留現有第六課漫畫主視覺，並用既有步驟、比較表、提醒與延伸資料元件補足操作圖解。
- 連結 Bambu Lab Wiki 作為官方延伸閱讀，不下載、重製或熱連結其權利未明的圖片。
- 只修改第六課需要的課程資料、共用渲染支援與測試；不改其他課程內容或全站視覺風格。

## 教學流程

第六課依學生實際操作順序分成五段：

1. **列印前檢查**：確認指定 A1、空白且正確安裝的紋理 PEI 平台、PLA 線材、0.4 mm 噴嘴，以及切片預覽沒有明顯異常。
2. **從 Bambu Studio 傳送**：完成切片後按下列印，核對 A1、平台與線材，保留自動調平，再送出工作。畫面文字以功能名稱為主，避免依賴可能隨版本改變的按鈕位置。
3. **觀察第一層**：比較正常、噴嘴過高、噴嘴過低與未黏住四種狀況。每種狀況都提供外觀線索與學生應採取的動作。
4. **異常處理**：先按暫停或停止，等待噴頭完全停止；不徒手接近移動中的噴頭，也不在熱床上直接清理纏料。若無法判斷，交由教師處理。
5. **冷卻取件**：列印完成後等待平台降溫，移除彈簧鋼板並輕微彎曲取件；刮刀不是初學者的優先方法，若必須使用，刀口不可朝向手掌。

## 視覺與資料呈現

- 現有漫畫主視覺繼續擔任整課概覽，圖說改成 A1 情境。
- Bambu Studio 操作使用編號步驟卡，避免複製官方軟體截圖。
- 第一層判讀使用四列比較表，欄位為「狀況、看起來、代表什麼、現在怎麼做」。
- 安全停止與冷卻取件各使用醒目提醒框。
- 每個官方資料連結標示為「Bambu Lab Wiki」，並以新分頁開啟。

## 案例與實作任務

3DBenchy 保留為延伸判讀案例，用來介紹橋接、懸空、圓孔與表面品質，不再與 20 分鐘內的第一次列印任務混用。

課堂實作改為使用教師指定、預估 20 分鐘內完成的小型 PLA 模型。學生記錄切片預估時間、實際時間、第一層觀察結果及取件前平台是否已冷卻。完成標準是學生親眼確認第一層，並能口述異常時的安全停止順序。

## 實作方式

主要內容放在 `course-data.js` 的第六課資料，沿用既有 `steps`、`compare`、`callout` 與 `sources` 欄位。只有當現有渲染器無法呈現必要內容時，才對 `course.js` 增加最小支援；不為單一課程引入框架、套件或新的資料來源。

靜態網站建置仍由 `scripts/build-site.js` 從同一份課程資料產生。若新增的既有欄位尚未被靜態建置器涵蓋，僅補上對應輸出，確保停用 JavaScript 時仍可讀到核心操作與安全資訊。

## 錯誤與安全處理

- 不把不同 Bambu Studio 版本的介面位置寫成固定座標或唯一畫面。
- 不教學生在噴頭移動、噴嘴高溫或平台尚熱時伸手處理失敗作品。
- 不把「暫停」描述成已解除所有高溫與移動風險；必須等待機器停止並確認安全。
- 不要求學生自行拆噴嘴、校正機構或處理無法判斷的硬體問題。
- 外部 Wiki 連結失效時不影響核心課程閱讀；必要操作仍完整寫在站內。

## 測試與驗收

採測試先行，先新增會因目前第六課內容不足而失敗的建置測試，再修改課程資料使其通過。驗收項目：

1. 建置後的第六課明確以 Bambu Lab A1 為示範機型。
2. 靜態正文包含列印前檢查、Bambu Studio 傳送、自動調平、安全暫停與冷卻取件。
3. 靜態正文包含正常、過高、過低與未黏住四種第一層判讀。
4. 實作任務使用 20 分鐘內的小模型，3DBenchy 僅作延伸案例。
5. 第六課至少提供官方傳送列印、第一層判讀與完成後取件三類 Bambu Lab Wiki 連結。
6. 所有 JavaScript 語法檢查、Node.js 測試與靜態網站建置皆通過。
