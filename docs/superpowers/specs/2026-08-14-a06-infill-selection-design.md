# A06「依作品需求選擇填充」課程設計

## 目標與範圍

新增進階課程 A06「依作品需求選擇填充」，用作品用途帶領讀者選擇填充，而不是把課程寫成設定百科。正文以展示模型、收納盒、支架與受壓零件四種案例為主線，建立「作品用途 → 主要受力 → 外殼與頂底層 → 填充圖樣 → 填充密度 → 切片預覽 → 小件測試」流程。

本次同時更新進階課程總覽、首頁進階課程導覽、課程數量與上一課／下一課連結。課程正文、圖片與導覽使用繁體中文；外部資料依內容放在對應段落，不集中在頁尾。

不在本課完整介紹 Bambu Studio 所有冷門填充圖樣，也不提供承載保證。所有密度數字均標示為切片起始值，功能件仍須以實際材料、機型、幾何與小件測試驗證。

## 課程定位

- 編號：A06
- 名稱：依作品需求選擇填充
- 階段：切片策略
- 時間：40–45 分鐘
- 類型：切片判讀＋單一變因比較
- 副標題：先判斷作品需要什麼，再決定圖樣與密度。

完成課程後，讀者可以：

1. 分辨外殼、稀疏填充、內部實心填充、頂底層與空腔。
2. 依展示模型、收納盒、支架與受壓零件選擇填充。
3. 比較 Lightning、Lines／Rectilinear、Gyroid、Cubic、Grid、Triangles 與 Concentric。
4. 判斷何時應先增加外殼、頂層或改善幾何，而不是只提高密度。
5. 在 Bambu Studio 預覽稀疏填充、內部實心填充與頂層路徑。
6. 完成固定其他條件、只改密度或圖樣的比較實驗。

## 七段課程正文

### 01｜填充不是把模型塞滿

用剖面圖分辨外殼、稀疏填充、內部實心填充、頂底層與空腔，說明填充主要用於支撐頂層、調整重量與剛性，以及協助外殼維持形狀。

明確拆解兩個誤解：15% 填充不等於 15% 強度；100% 填充也不會自動修正材料、方向與幾何問題。

### 02｜選填充前先回答四個問題

依序判斷：作品是否承受力量、主要受力類型、是否有大面積頂部、優先目標是強度／重量／速度／柔軟度。連結 A05，提醒讀者先處理列印方向與幾何，再決定填充。

### 03｜七種常用填充圖樣

正文只介紹 Lightning、Lines／Rectilinear、Gyroid、Cubic、Grid、Triangles 與 Concentric。每種圖樣必須列出路徑特徵、適合用途與限制，並以俯視及立體剖面圖解釋。

不得宣稱某一圖樣在所有條件下最強。Grid 等同層交叉圖樣應提醒讀者留意交叉點材料堆積與噴嘴摩擦；Gyroid 應描述為多方向較均衡且同層通常不自我交叉，而不是絕對各向同性。

### 04｜依四種作品選擇

| 作品 | 候選圖樣 | 起始密度 | 優先檢查 |
|---|---|---:|---|
| 展示模型、公仔 | Lightning、Lines | 5–12% | 頂層是否有足夠支撐 |
| 收納盒、外殼 | Lines、Gyroid | 10–18% | 外殼圈數、底層厚度與盒口剛性 |
| 支架、功能零件 | Gyroid、Cubic | 15–30% | 方向、根部圓角、孔周與外殼 |
| 受壓底座、墊塊 | Cubic、Triangles、Grid | 25–40% | 接觸面、頂底層、外殼與材料蠕變 |

40% 以上不列為一般預設；必須先說明需求並以小件測試確認。

### 05｜為什麼不是密度越高越好

解釋強度增加通常不是線性，並比較相同材料預算下增加外殼、提高填充、增加圓角／肋條及改變列印方向的差異。正文要指出：彎曲件常先受益於外殼與幾何；受壓件才更可能明顯受益於較高填充；大面積頂層則需同時檢查頂層厚度與內部支撐。

### 06｜在 Bambu Studio 實際設定

操作流程固定為：選取模型 → 打開強度設定 → 設定稀疏填充密度 → 選擇稀疏填充圖樣 → 檢查外殼圈數與頂底層 → 切片 → 以線條類型逐層預覽 → 記錄時間、重量與材料長度 → 一次只修改一個設定。

介面圖採原創重繪，不直接複製官方畫面；圖說標示介面與設定名稱參考 Bambu Studio。

### 07｜單一變因填充實驗

必做實驗固定模型、材料、方向、外殼、頂底層與 Gyroid 圖樣，只比較 10%、20%、30% 密度，記錄時間、重量、變形、裂縫位置與破壞方式。

延伸實驗固定 20% 密度，只比較 Lines、Gyroid、Cubic。兩個實驗分開呈現，避免同時改變密度與圖樣。

課程最後提供可填寫的判斷表：作品需求、候選圖樣、起始密度、外殼／頂層檢查、預覽結果與測試結果。

## 圖片規格

製作十張 1536×1024、3:2 橫式 WebP 教學圖：

1. 模型剖面與外殼、稀疏填充、內部實心填充、頂底層、空腔。
2. 相同模型的 0%、10%、20%、40% 密度比較。
3. 用途、受力、頂層、重量與時間的四問決策流程。
4. 七種常用填充的俯視與立體剖面矩陣。
5. Gyroid、Cubic、Grid 的同層交叉與三維路徑比較。
6. 展示模型與 Lightning 內部支撐。
7. 收納盒的外殼、底層、盒口與稀疏填充。
8. 支架的傳力路徑、外殼與 Gyroid／Cubic。
9. 受壓墊塊的接觸面、頂底層與內部傳力。
10. Bambu Studio 設定與逐層預覽操作圖。

沿用進階課程的米白背景、深墨線稿、綠／紫／藍／紅功能色與粗體繁體中文。主要標籤需大而清楚，手機版可辨識；每張圖下方另有 3–5 點圖解步驟。所有圖片可用既有燈箱放大、前後切換及 Esc 關閉。

提示詞集中保存於 `docs/image-prompts/advanced-a06-infill-selection.md`，包含共同美術規格、逐圖提示詞、精確文字、禁止項目與 alt 文字。
