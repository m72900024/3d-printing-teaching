# 進階課程 A08–A12 設計規格

## 目標

將現有七堂進階課程擴充為十二堂，讓學習路線從「穩定列印」繼續前進到「尺寸精準、效率取捨、表面精修與多色製作」。內容以 Bambu Lab A1、Bambu Studio 與 AMS Lite 為主要操作情境，使用繁體中文、功能性圖解、官方引用及單一變因實驗。

## 範圍與分期

這是五個可獨立完成、驗證與發布的課程子專案，依序製作：

1. A08「流量校正與建立線材預設」
2. A09「依裝配需求設計公差」
3. A10「依細節與效率選擇噴嘴」
4. A11「曲面、頂面與接縫精修」
5. A12「AMS Lite 多色列印與減少浪費」

每完成一堂即驗證導覽、行動版、課程進度、圖片與外部連結，再更新公開網站。不得為等待後續課程而留下不可用的入口。

## 共通教學結構

每堂課沿用 A01–A07 的資料驅動版型，不另做新的頁面系統：

- 課程標題、摘要、時間與類型
- 五項可觀察的學習成果
- 5–7 個主題段落
- 每段至少一張功能性教學圖
- 正確／錯誤、設定前／後或不同需求的對照
- 一個可安全完成的單一變因實作
- 一句可自我檢核的課程結語
- 各段就近標示 Bambu Lab Wiki、Bambu Studio 官方文件或可信的一手資料

圖片文字必須使用繁體中文，箭頭、數值、設定名稱與觀察位置要能直接服務課文。圖片不得只是裝飾，也不得以生成圖假裝成 Bambu Studio 真實截圖；介面示意圖需明確標示為示意。

## 三階段導覽

進階課程總覽與網站課程選單顯示以下階段：

- 第一階段「建立穩定基準」：A01–A04
- 第二階段「功能與結構設計」：A05–A08
- 第三階段「精準、表面與效率」：A09–A12

首頁進階課程卡在 A08 發布時更新為「8 堂課已開放」，後續逐堂遞增；不得提前宣稱尚未完成的課程已開放。A12 完成後改為「12 堂課已開放」。

## A08：流量校正與建立線材預設

### 學習成果

學生完成後能：

1. 分辨 Flow Dynamics 與 Flow Rate 解決的問題。
2. 判斷更換材料、品牌、噴嘴或列印條件後是否需要重新校正。
3. 依 Bambu Studio 的校正流程選出結果，而不是背誦通用數值。
4. 辨認過度擠出、擠出不足與較穩定出料的外觀線索。
5. 用可追溯名稱保存材料預設及校正紀錄。

### 課程段落

1. **先確認是否需要校正**：原廠預設、第三方線材、噴嘴或批次改變時的判斷；先排除受潮、堵塞與錯誤材料預設。
2. **兩種校正各自處理什麼**：Flow Dynamics 處理速度變化時的壓力響應；Flow Rate 處理穩態擠出量。
3. **Flow Dynamics 操作與判讀**：選擇一致、轉角較乾淨的測試結果，保留機型、噴嘴與材料條件。
4. **Flow Rate 操作與判讀**：分兩輪比較表面，選出不過度堆料也不留明顯間隙的結果。
5. **把結果存成可追溯預設**：名稱包含材料、品牌、噴嘴與日期；不覆蓋原始系統預設。
6. **校正後驗證**：以固定小件比較校正前後，只替換新材料預設。

### 圖片配置

至少製作七張圖：

1. 是否需要校正的決策流程
2. Flow Dynamics 與 Flow Rate 的功能差異
3. 壓力響應不足、過度與較穩定的轉角對照
4. Flow Rate 測試片表面判讀
5. 過度擠出／適中／擠出不足剖面
6. 材料預設命名與保存流程
7. 校正前後固定小件比較

所有圖片提示詞一併保存於 `docs/image-prompts/advanced-a08-illustrations.md`，成品放在 `assets/advanced-a08/illustrations/`。

### 內容邊界

- 不提供可套用所有材料的固定 K 值或流量倍率。
- 不把校正當成所有品質問題的答案。
- 受潮與堵塞只做校正前排除，詳細處理連回 A01、A02。
- 公差、噴嘴尺寸、表面精修與多色減廢留給 A09–A12。
- 涉及異常升溫、冒煙、電氣或熱端拆卸時停止操作並尋求支援。

## A09–A12 內容邊界

### A09 依裝配需求設計公差

以滑動、定位、緊配與螺絲孔為四種用途，教學生量測名義尺寸與實際尺寸，再用孔洞補償、輪廓補償及象腳補償做單一變因試片。不得宣稱存在通用公差值；受力方向仍連回 A05。

### A10 依細節與效率選擇噴嘴

以同一模型比較 0.2、0.4、0.6 mm 噴嘴對細節、線寬、牆厚、時間與材料的影響。材料相容性只作安全檢查，不重複 A04 的選材內容。

### A11 曲面、頂面與接縫精修

聚焦自適應層高、熨平、頂面圖樣、接縫位置與 Scarf Seam。Fuzzy Skin 作為選修延伸。A02 負責診斷異常，A11 負責有意識地設計表面。

### A12 AMS Lite 多色列印與減少浪費

涵蓋模型上色、槽位對應、換色層、沖刷量、擦料塔與切片預覽。比較「顏色多」和「換色次數多」的差異，透過方向與著色區域減少材料浪費，不鼓勵未經驗證地將沖刷料填入所有功能區。

## 實作與驗證

每一堂新增資料物件、獨立 HTML 入口、圖片資料夾及提示詞文件。共用呈現仍由 `advanced-app.js`、`advanced.css`、`site-navigation.js` 與既有建置程式處理，只有在新內容確實需要且測試可證明時才做小幅共用修改。

每堂發布前至少完成：

- 自動測試全部通過
- 建置程式產生的課程頁與資料一致
- 課程編號、上一堂／下一堂、首頁及進階總覽連結正確
- 桌面與窄螢幕沒有圖片裁切或文字遮擋
- 圖片載入成功且替代文字有效
- 外部引用可開啟，且引用文字不誤稱為官方認證
- 頁面沒有簡體中文、日文或未翻譯的教學句子
