# 靜態課程、手機選單、快取與授權設計

## 目標

在不改變首頁課程時間與既有視覺風格的前提下，讓 12 個課程頁面即使沒有 JavaScript 也能閱讀完整核心正文，並改善手機課程選單、資源快取與專案授權資訊。

## 範圍

- 保留首頁目前顯示的課程時間，不同步 `course-data.js` 的時間。
- 將 `course-data.js` 的核心文字內容預先產生到部署用 HTML。
- 保留現有 JavaScript 動畫、測驗、影片與課程進度功能。
- 改善手機課程選單的關閉方式與無障礙狀態。
- 對本機 CSS／JavaScript 使用內容雜湊作為快取版本。
- 新增程式與教材的雙授權說明。
- 補齊 GitHub About 的描述、網站網址與 topics。

## 架構

新增一支無外部套件的 Node.js 建置程式。它會把公開網站檔案複製到 `_site`，讀取 `course-data.js`，將每課標題、導言、學習目標、段落、任務、檢核與前後課導覽寫入對應 HTML，再為本機 CSS／JavaScript 參照加入檔案內容雜湊。GitHub Pages 只發布 `_site`。

瀏覽器載入 JavaScript 後，現有 `course.js` 仍會用同一份課程資料建立互動內容；未載入 JavaScript 時，使用者則閱讀建置時產生的靜態正文。兩種模式共用 `course-data.js`，避免另維護一份教材內容。

## 靜態正文

靜態頁面至少包含：

- 課程階段、編號、標題、副標題、導言與學習目標。
- 每個段落的標題、正文、要點、步驟、比較表與提醒。
- 實作任務與離開前確認。
- 全部課程選單及上一課／下一課連結。
- 一段只在 JavaScript 關閉時顯示的說明，指出動畫、測驗與進度功能需要 JavaScript，但正文可正常閱讀。

圖片、影片播放器、動畫與測驗仍由 JavaScript 增強；靜態模式以完整核心教學文字與可用導覽為驗收標準。

## 手機課程選單

在 900px 以下沿用既有側欄，新增半透明遮罩。選單按鈕會設定 `aria-controls` 與 `aria-expanded`；以下操作都會關閉選單：

- 再次按下課程按鈕。
- 點擊遮罩。
- 點擊任一課程連結。
- 按下 Escape。
- 視窗切回桌面寬度。

開啟時鎖定背景捲動；關閉時把焦點還給課程按鈕，但由課程連結導覽或切換桌面寬度時不強制搶回焦點。

## 快取策略

建置程式計算每個本機 CSS／JavaScript 檔案的 SHA-256 內容雜湊，取前 12 碼加入 `?v=`。同一檔案在所有頁面會得到相同版本；內容未變時版本穩定，內容改變時自動更新，不再人工維護日期字串。

## 授權與 GitHub 門面

- 網站程式碼採 MIT License。
- 原創教材文字與原創／AI 輔助製作的教學插圖採 Creative Commons Attribution 4.0 International。
- 第三方照片、影片、商標及外部資料不重新授權，依其原始來源條款使用。
- README 清楚連結授權與公開網站。
- GitHub About 使用簡短中文描述、公開網站網址，以及 `3d-printing`、`fdm`、`education`、`bambu-studio`、`github-pages` topics。

## 部署與錯誤處理

GitHub Actions 在 push、手動觸發與 pull request 時執行建置和檢查；pull request 只驗證，不部署。若課程資料缺少對應 HTML、靜態欄位未生成、資源不存在或版本參數不一致，流程立即失敗，避免發布空白課程。

## 測試與驗收

採測試先行：先建立會因目前空白課程骨架而失敗的 Node.js 測試，再加入建置程式使其通過。驗收項目：

1. `_site/courses` 有 12 個課程頁面。
2. 關閉 JavaScript 時，每頁仍包含該課標題、導言、段落、任務與檢核。
3. 所有本機 CSS／JavaScript 參照均存在並包含 12 碼內容雜湊。
4. 手機選單的開啟、遮罩、連結、Escape 與桌面切換行為由 DOM 測試或可執行的最小測試頁驗證。
5. `node --check` 通過所有 JavaScript。
6. 建置與完整測試皆以結束碼 0 完成。
