# 首頁課程分級與動漫主視覺設計

## 目標

將首頁改為清楚的課程入口與網站介紹。現有 12 堂課全部歸入「初階課程」；「進階課程」先顯示規劃中入口，內容留待後續獨立設計。首頁原本以 CSS 組成的印表機示意圖，改為一張活潑、易懂的動漫風 3D 印表機教學插圖。

## 首頁資訊架構

1. 頂部導覽改為「初階課程」、「進階課程」、「網站介紹」。
2. 主視覺區左側說明網站用途，右側顯示動漫風 3D 印表機教學插圖。
3. 主視覺的主要按鈕前往初階課程，次要按鈕前往網站介紹。
4. 主視覺下方新增兩張明確的課程入口卡：
   - 初階課程：標示「12 堂課」，可前往現有課程總覽。
   - 進階課程：標示「規劃中」，保留未來入口，但不建立空白課程頁。
5. 現有三個學習階段保留在初階課程區內，繼續作為 12 堂課的細分進度。
6. 網站介紹區以簡短文字說明課程適合對象、教學方式與完成後能做到的事情。

## 文案方向

首頁以學生能理解的繁體中文說明，不使用技術行銷用語。主標題聚焦「從零開始，完成第一件 3D 列印作品」。網站介紹必須涵蓋：安全操作、Bambu Studio 切片、A1 實作、參數理解與問題排除。

進階課程卡清楚標示尚未開放，不使用可點擊卻沒有內容的假連結。可顯示預計涵蓋的方向，例如校正、材料調校、設計最佳化與系統化實驗，但不承諾堂數。

## 動漫主視覺

製作一張橫式首頁圖片，主題為明亮的 3D 列印教室：一位年輕學習者與一台開放式 FDM 3D 印表機互動，清楚看見線材架、列印頭、平台與正在成形的小作品。風格採乾淨、活潑的日系動漫教學插畫，使用青藍、珊瑚橘與明黃作為重點色。

圖片不生成文字、品牌標誌或操作警示，以免出現錯字；所有說明由可存取的 HTML 文字呈現。圖片需保留足夠留白，裁切到桌機與手機比例時仍能看見人物、印表機與作品。圖片另附繁體中文替代文字，生圖提示詞保存於 `docs/image-prompts/homepage-anime-hero.md`。

## 視覺與互動

- 延續現有網站的卡片、進度記錄、揭露動畫與課程連結行為，不改寫課程頁。
- 首頁改為較活潑的動漫教室語言，但維持清楚對比、可見的鍵盤焦點與易讀文字。
- 唯一主要視覺焦點是動漫主圖；其他裝飾保持節制。
- 桌機採文字與圖片左右配置；手機改為文字在上、圖片在下。
- 初階與進階入口卡在桌機並排、手機直向排列。
- 尊重 `prefers-reduced-motion`，不新增無法關閉或影響閱讀的動畫。

## 技術範圍

修改範圍限於首頁 HTML、首頁共用樣式、必要的首頁互動／進度腳本、首頁圖片與提示詞文件。靜態建置仍輸出至 `_site`，課程資料與 12 個課程頁內容不變。

進階課程本次只有不可操作的規劃中卡片，不新增網址、資料結構或假內容。未來設計進階課程時，再獨立定義課綱與路由。

## 驗收方式

- 首頁導覽可正確移動到初階課程、進階課程與網站介紹。
- 初階入口明確顯示 12 堂課，並可進入既有課程。
- 進階入口明確顯示規劃中，且不造成死連結。
- 動漫主圖在桌機與手機不溢出、不遮住文字，並有合適替代文字。
- 現有課程完成進度仍能讀取與呈現。
- 關閉 JavaScript 時，首頁的介紹、課程入口和 12 堂課連結仍可閱讀與使用。
- 現有自動測試通過，並新增首頁分級與圖片資源檢查。
- 建置成功後，以桌機與手機尺寸檢查首頁，並確認公開網址回應正常。

## 不包含

- 不在本次撰寫或建立進階課程內容。
- 不修改現有 12 堂初階課程的教材內容。
- 不重新設計課程內頁或側邊導覽。
- 不在生成圖片內放置需要精確拼字的文字。
