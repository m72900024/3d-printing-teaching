# 課程 02 排版調整

日期：2026-08-06

## 發現的問題

公開頁面以 1280 × 720 視窗量測時：

- 學習目標區高 588 px，三張卡片各佔一整列，造成頁首總高度約 1099 px。
- 三種機構圖以正方形顯示，圖片本身高約 696 px，連同圖說與卡片後整個區塊高約 1006 px。
- 四欄比較表在手機寬度下會把內容壓得過窄。

## 調整方式

- 901 px 以上：三張學習目標改成三欄直式卡片，圖片使用 16:10 比例。
- 900 px 以下：目標卡改為單欄橫式，避免文字欄過窄。
- 機構大圖在桌面裁成 4:3 顯示，手機仍保留正方形，兼顧高度與辨識度。
- 三種機構說明維持桌面三欄、手機單欄。
- 比較表使用固定欄寬與橫向捲動，避免手機版文字被擠成直排。
- 將比較表的最小內容寬度限制在課程欄位內，橫向捲動只發生在表格本身，不會撐寬整頁。
- 更新課程 02 的 CSS 與腳本快取版本為 `20260806-04`。

## 驗證項目

- 桌面 1280 px：學習目標改為三欄後，目標區由 588 px 降至 349 px；機構圖片由 696 px 降至 522 px。
- 手機 390 px：目標卡單欄、機構說明單欄；比較表顯示寬 333 px、內容寬 670 px，可在表格內橫向滑動且不撐寬整頁。
- 課程內容、圖片替代文字與互動功能維持不變。
